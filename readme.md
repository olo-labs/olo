# Why We Started OLO

Building enterprise AI applications shouldn't require writing orchestration logic from scratch every time.

OLO separates:

- Workflow Definition
- Runtime Kernel
- Workers
- AI Agents
- Tools
- Human Interaction
- Deployment

so each evolves independently.

The result is a platform where workflows remain portable while execution scales from local development to distributed production environments.
